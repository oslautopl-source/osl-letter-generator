OSL LETTER GENERATOR - UPDATE

Files in this package:
- index.html: home page with Chola TA and Credit Request buttons.
- chola-ta.html: Chola TA request form and single-page A4 PDF generator, based on the supplied Chola TA PDF.
- credit-request.html: existing Credit Request generator.

To update GitHub Pages:
1. Extract this ZIP.
2. Upload/replace index.html, chola-ta.html, and credit-request.html in the repository root.
3. Keep the existing header.png, footer.png, and stamp_signature.png in the same repository root. Do not delete them; the forms reference these exact names.
4. Commit changes, wait for GitHub Pages to deploy, then refresh the site.

Chola TA form:
- Letter date defaults to today's local date.
- Trade advance amount and amount in words can be changed before preview/PDF.
- Dealer bank details follow the uploaded reference PDF.
- PDF generation uses selectable text and places header/footer/stamp assets at preserved aspect ratios on one A4 page.

Important: The attached reference contained this amount wording: "Rs. 15000000.00 Lakhs". The template preserves that wording pattern. Please confirm the intended amount/unit before sending any generated business letter.
